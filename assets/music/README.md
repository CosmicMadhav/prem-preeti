# The soundtrack 🎵

The six mp3s in this folder are the soundtrack. The music **changes with
the mood of each section** and cross-fades as she scrolls; the button at
the bottom-left mutes the lot.

| Track | Plays during |
|---|---|
| `Love_JoTumMereHo.mp3` | The gate, the hero, "Us, so far" — **and again at the end**, so it comes full circle |
| `Love_UntilIFoundYou.mp3` | Our story, chapter by chapter |
| `Love_TheWalters.mp3` | Moments, the pandas, the memory game |
| `Love_LoveMeLikeYouDo.mp3` | Reasons, Open when…, the map, the quiz |
| `Love_Nadaaniyan.mp3` | The birthday and the cake |
| `Love_EDPerfect.mp3` | The proposal |

To change which song plays where, edit `js/content.js` → `music.tracks`.
Each track lists the section ids it covers under `for`. `volume` and
`fade` (seconds of cross-fade) are in the same block.

**To add or swap a song:** drop the mp3 in here and point a track at it.

---

## Your voice

Record yourself reading the letter and save it here as **`voice.mp3`**.
A *"Hear me say it"* button appears under the letter automatically. If the
file isn't there, the button simply doesn't appear.
