then you don't have to edit any code at all.

---

**Tips**

- `.jpg`, `.png` and `.webp` all work. If you use a different extension,
  update the filename in `js/content.js`.
- Keep each photo under ~500 KB so the site loads fast on her phone.
  Any free image compressor (e.g. squoosh.app) will do it.
- Missing a photo? Nothing breaks — the site shows a soft placeholder
  telling you which filename it's waiting for.
